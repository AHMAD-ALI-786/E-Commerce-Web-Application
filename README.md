## Features

- Add and display product information.
- Store and retrieve product data using `localStorage`.
- Search products by name and category.
- Sort products by price, name and category.
- Display product information dynamically using JavaScript and the DOM.
- Manage product data using JavaScript arrays and objects.
- Generate unique product IDs using `crypto.randomUUID()`.

## Tech Stack

## Data Storage

This project uses the browser's `localStorage` to save and retrieve product data.

- Data can remain available after refreshing the page.
- The data is stored locally in the browser, not in a remote database.
- Clearing the browser's site data can remove the saved products.
- Since `localStorage` operations are synchronous, this project does not require Promises for its storage operations.

Understanding this distinction has helped me see why different applications need different data-storage approaches.
